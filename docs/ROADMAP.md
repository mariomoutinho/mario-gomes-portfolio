# Roadmap

## Etapa 1 — Fundação técnica (autorizada)

Estrutura React/TypeScript/Vite, npm e lockfile, CSS Modules, reservas de tokens, qualidade de código, testes de DOM e navegador, Git local, documentação e workflow de CI. A aplicação permanece visualmente vazia.

A conclusão das verificações locais fica registrada em [VALIDATION.md](VALIDATION.md). GitHub remoto, execução do workflow no GitHub e proteção de main dependem de configuração da conta e autorização de publicação.

## Etapa 2 — Especificação (aguarda briefing)

Receber direção artística, identidade, referências, conteúdo, mídia, acessibilidade, componentes, comportamento responsivo e experiência. Revisar licenças e permissões. Aprovar critérios de aceitação e orçamento de performance antes de implementar.

## Etapa 3 — Implementação (não autorizada)

Construir seções e componentes a partir da especificação aprovada; validar responsividade, teclado, mídia, performance e movimento reduzido com testes que reflitam comportamentos reais.

## Etapa 4 — Publicação (não autorizada)

Definir hospedagem, domínio, política de privacidade/analytics quando aplicável, SEO e metadados de compartilhamento; retirar noindex após revisão; executar homologação; publicar somente com autorização específica. Sem deploy automático nesta fundação.
